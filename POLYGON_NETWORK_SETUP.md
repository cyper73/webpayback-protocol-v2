# Setup Polygon Network - COMPLETED ✅

## 🔧 PROBLEMA IDENTIFICATO
Balancer non mostra Polygon perché il network non è aggiunto al tuo wallet.

## ✅ SOLUZIONE: Aggiungi Polygon al Wallet

### 📱 Se Usi MetaMask:

#### Metodo 1: Automatico (CONSIGLIATO)
1. **Vai su chainlist.org**
2. **Cerca "Polygon"**
3. **Clicca "Add to MetaMask"** accanto a Polygon Mainnet
4. **Conferma l'aggiunta** nel popup MetaMask

#### Metodo 2: Manuale
1. **Apri MetaMask**
2. **Clicca il dropdown network** (attualmente mostra Ethereum)
3. **Clicca "Add Network"** in fondo
4. **Inserisci questi parametri:**

```
Network Name: Polygon Mainnet
New RPC URL: https://polygon-rpc.com/
Chain ID: 137
Currency Symbol: MATIC
Block Explorer URL: https://polygonscan.com/
```

5. **Clicca "Save"**

### 🔄 Dopo Aver Aggiunto Polygon:

#### 1. Switch a Polygon
- Nel dropdown MetaMask, seleziona **"Polygon Mainnet"**
- Il simbolo dovrebbe cambiare da ETH a MATIC

#### 2. Verifica Token
- I tuoi USDT e WPT dovrebbero essere visibili
- Se non li vedi, aggiungi i contracts:
  - **USDT**: `0xc2132D05D31c914a87C6611C10748AEb04B58e8F`
  - **WPT**: `0x9408f17a8B4666f8cb8231BA213DE04137dc3825`

#### 3. Torna a Balancer
- **Refresha la pagina** app.balancer.fi
- **Riconnetti il wallet**
- Ora dovresti vedere **Polygon** nella lista network!

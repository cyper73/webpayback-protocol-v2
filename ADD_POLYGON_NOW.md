# AGGIUNGI POLYGON ADESSO - Step by Step

## 🎯 SITUAZIONE: Polygon non è nella lista del tuo wallet

## ✅ SOLUZIONE IMMEDIATA:

### METODO 1: Chainlist (PIU' VELOCE)
1. **Apri nuova tab**: vai su **chainlist.org**
2. **Cerca**: digita "Polygon" nella barra ricerca
3. **Trova**: "Polygon Mainnet" (Chain ID: 137)
4. **Clicca**: "Add to MetaMask" o "Connect Wallet"
5. **Conferma**: nel popup che appare

### METODO 2: Manuale nel Wallet
1. **Nel tuo wallet**, clicca in alto dove c'è il network
2. **Clicca**: "Add Network" o "Aggiungi Rete"
3. **Inserisci ESATTAMENTE**:

```
Nome Rete: Polygon Mainnet
URL RPC: https://polygon-rpc.com/
Chain ID: 137
Simbolo: MATIC
Explorer: https://polygonscan.com/
```

4. **Salva** la configurazione

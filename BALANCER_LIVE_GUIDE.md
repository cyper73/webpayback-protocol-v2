# Guida Live: Creazione Pool Balancer V2 USDT/WPT

## 🚀 ORA PROCEDIAMO - Hai Polygon nel Wallet!

### STEP 1: Accedi a Balancer
1. **Vai su app.balancer.fi** (nuova tab)
2. **Clicca "Connect Wallet"** (in alto a destra)
3. **Seleziona il tuo wallet** (MetaMask/WalletConnect)
4. **IMPORTANTE**: Seleziona **Polygon** dal dropdown network
5. **Conferma connessione**

### STEP 2: Vai alla Creazione Pool
1. **Nel menu principale**, clicca **"Pools"**
2. **Clicca "Create Pool"** (solitamente in alto o centro pagina)
3. **Si aprirà wizard creazione pool**

### STEP 3: Selezione Tipo Pool
1. **Ti mostrerà diversi tipi di pool**
2. **Seleziona "Weighted Pool"** (NON Composable Stable)
3. **Clicca "Next" o "Continue"**

### STEP 4: Aggiungi Token USDT
1. **Clicca "Add Token" o "Select Token"**
2. **Incolla**: `0xc2132D05D31c914a87C6611C10748AEb04B58e8F`
3. **Dovrebbe apparire "USDT"** con logo
4. **Imposta peso: 80%** (0.8 se in decimali)

### STEP 5: Aggiungi Token WPT
1. **Clicca "Add Token"** per secondo token
2. **Incolla**: `0x9408f17a8B4666f8cb8231BA213DE04137dc3825`
3. **Dovrebbe apparire "WPT"** o nome simile
4. **Imposta peso: 20%** (0.2 se in decimali)

### STEP 6: Imposta Swap Fee
- **Fee: 0.5%** (0.005 se chiede decimali)
- Ottimale per token nuovi come WPT

### STEP 7: Liquidità Iniziale
**Quanto vuoi investire?** (Es: $200)
- **USDT**: 160 USDT (80% di $200)
- **WPT**: 4,000 WPT (20% = $40 valore)

**Inserisci le quantità nei campi**

### STEP 8: Approvazioni
1. **Clicca "Approve USDT"** → Conferma in wallet
2. **Clicca "Approve WPT"** → Conferma in wallet
3. **Aspetta conferme blockchain** (1-2 min)

### STEP 9: Crea Pool
1. **Clicca "Create Pool"**
2. **Verifica parametri finali**:
   - Weights: 80% USDT, 20% WPT
   - Fee: 0.5%
   - Amounts corretti
3. **Conferma transazione finale**

### STEP 10: Salva Pool Address
- **Dopo creazione**, copia e salva l'indirizzo pool
- **Riceverai BPT tokens** (Balancer Pool Tokens)

---

## 💰 CALCOLATORE RAPIDO

**Per investimento $X:**
- USDT needed: X × 0.8
- WPT needed: (X × 0.2) ÷ 0.01 = X × 20

**Esempi:**
- $100: 80 USDT + 2,000 WPT
- $200: 160 USDT + 4,000 WPT  
- $500: 400 USDT + 10,000 WPT

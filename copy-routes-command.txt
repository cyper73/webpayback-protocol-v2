COMANDO SEMPLICE PER COPIARE IL FILE AGGIORNATO:

1. Nel tuo PowerShell, dalla directory webpayback, esegui:

```bash
# Scarica il file aggiornato direttamente da Replit
curl -o server/routes.ts "https://webpayback-protocol.cyper73.repl.co/download/routes.ts"
```

2. OPPURE copia manualmente il contenuto:

Vai su: https://webpayback-protocol.cyper73.repl.co/routes.ts

E sostituisci il contenuto del tuo file server/routes.ts locale.

3. Poi commit:
```bash
git add server/routes.ts
git commit -m "feat: Add DeepSeek and Grok AI detection support"
git push origin webpayback
```

ALTERNATIVE: Se il download non funziona, posso creare un endpoint specifico per il download del file.

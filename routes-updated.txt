Ecco il comando per copiare il file routes.ts aggiornato:

COMANDO WINDOWS (PowerShell):
```powershell
# Salva questo contenuto in un file temporaneo e poi copialo
$content = @"
[IL CONTENUTO VERRÀ AGGIUNTO QUI]
"@
$content | Out-File -FilePath "server\routes.ts" -Encoding UTF8
```

COMANDO UNIX/LINUX:
```bash
# Copia direttamente
cat > server/routes.ts << 'EOF'
[IL CONTENUTO VERRÀ AGGIUNTO QUI]
EOF
```
